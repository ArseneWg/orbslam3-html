对象与图结构精读：为什么地图能“连起来”

Frame、KeyFrame、MapPoint、Map、Atlas 不是命名包装；它们的观测关系和连接规则直接决定后端优化与闭环图结构。

阶段一概览源码精读首页

Frame → KeyFrame → MapPoint

源码把“当前观测”和“长期地图”分开管理：Frame 是短生命周期当前状态；KeyFrame 进入图结构；MapPoint 保存 3D 位置和多关键帧观测。

Atlas → Map

Atlas 管理多个 Map。Tracking 彻底 LOST 且地图足够大时会 CreateMapInAtlas()，最终调用 Atlas::CreateNewMap()，旧 map 被置 stored，新 map 成为 current。
