你能从这个站里学到什么？

这是一套面向 ORB-SLAM3 单目 + IMU 的源码学习网站。它把官方工程拆解为一条完整的调用链：数据集入口 → System 构建 → Tracking → 单目初始化 → IMU 预积分/初始化 → Local Mapping → Loop Closing → Optimizer。每个节点单独成页，尽量用图、流程图、交互式 3D 小演示解释“这一段代码在系统中扮演什么角色”。

阅读建议

第 1 遍：先看「框架总览」和「数据入口」，建立整体地图。
第 2 遍：顺着 System → Tracking → LocalMapping 读主干。
第 3 遍：专门看「单目初始化」和「IMU 预积分」，理解视觉与惯性的连接点。
第 4 遍：再看 Loop Closing、Optimizer、数据结构，形成闭环。
方法论：源码学习时不要试图一次性“啃完所有公式”。先盯住 函数入口、线程边界、对象生命周期 和 数据从哪里来，往哪里去。

单目 + IMU 完整流程图

1. 数据入口例子程序读取图像与 IMU，按图像帧切片收集 IMU 样本，然后调用 TrackMonocular()。 2. System 启动加载词袋、设置、Atlas、关键帧数据库，拉起 Tracking / LocalMapping / LoopClosing / Viewer。 3. Tracking灰度化、提特征、建 Frame、执行主状态机，并决定是否创建新关键帧。 4. 单目初始化两视图匹配、恢复相对位姿、三角化，生成第一张地图；此时尺度仍可能模糊。 5. IMU 融合在帧间进行预积分，随后通过惯性初始化估计重力/尺度/偏置，将视觉地图升级为视觉惯性地图。
6. Local Mapping处理新关键帧、剔除坏点、三角化新点、局部优化、关键帧裁剪。 7. Loop Closing利用 BoW 与几何验证查找回环/合图候选，做图校正和地图融合。 8. OptimizerPose Optimization、Local BA、Inertial BA、位姿图优化等在此落地。 9. 数据结构Frame、KeyFrame、MapPoint、Map、Atlas 等共同支撑前后端。 10. 回看总览把线程、对象、函数调用关系拼回一张全局认知图。

前端看什么

以 Tracking 为中心，理解相机位姿如何被预测、匹配、优化和更新。

后端看什么

以 LocalMapping 和 LoopClosing 为中心，理解地图如何被持续优化并修正漂移。

视觉惯性看什么

重点盯住 PreintegrateIMU 与 InitializeIMU：它们是从“只有相对视觉几何”走向“有尺度与重力约束”的关键。

源码范围说明

本网站主要参考的目录

  • Examples/Monocular-Inertial/：单目 + IMU 的例子程序与数据入口。
  • include/System.h、src/System.cc：系统总入口与线程装配。
  • include/Tracking.h、src/Tracking.cc：前端状态机与位姿跟踪。
  • src/LocalMapping.cc：局部建图与 IMU 初始化。
  • src/LoopClosing.cc：闭环与合图。
  • src/Optimizer.cc：视觉/惯性优化实现。
  • src/Frame.cc、src/KeyFrame.cc、src/MapPoint.cc：核心对象语义。

不是本网站重点的内容

  • 编译环境避坑、Ubuntu 依赖安装。
  • ROS 节点工程封装。
  • 立体、RGB-D、鱼眼等其它传感器模式的差异化细节。
  • 逐公式推导完整论文；本网站以“源码工作流”视角讲解，不以数学推导为主线。
