mptLoopClosing = new thread(&ORB_SLAM3::LoopClosing::Run, mpLoopCloser);

mpTracker->SetLocalMapper(mpLocalMapper);

mpLoopCloser->SetLocalMapper(mpLocalMapper);

System 是调度层，不是前端算法层

它把 IMU 样本推入 Tracker 队列，再把图像送给 GrabImageMonocular，最后缓存结果。

源码直接可见

IMU 样本先入队，图像随后触发计算

从调用顺序看，当前帧的 IMU 包先被 GrabImuData 全部加入队列，然后才处理图像。

源码直接可见

定位模式会停 LocalMapping

TrackMonocular 中的 localization mode 分支会 RequestStop LocalMapper，并把 Tracker 切到 only tracking。

由源码行为推导

线程间共享地图需要显式同步

System 和后续模块频繁使用 mutex；这是多线程 SLAM 设计必然带来的同步成本。
