2. 必须真正理解的术语

Frame

每张输入图像对应的临时前端状态，包含特征、描述子、当前 pose、地图点关联，以及惯性状态。

KeyFrame

被长期保留到地图图结构中的 Frame。它参与共视关系、BoW 检索、局部 BA、回环与惯性时间链。

MapPoint

不仅是 3D 坐标，还保存被哪些 KeyFrame 观测、代表性描述子、可见性统计与地图归属。

BoW

把 ORB 描述子转换成词袋/FeatureVector，用于快速匹配同一 vocabulary node 内的特征和 place recognition。

Preintegration

把两个帧或关键帧之间的大量 IMU 采样压成可复用的相对运动约束，并保留 bias 相关修正。

SE(3)

刚体位姿：旋转 + 平移，不包含尺度。

Sim(3)

相似变换：旋转 + 平移 + 尺度。单目闭环/地图对齐中尤其重要。

Covisibility

两个 KeyFrame 共享 MapPoint 的程度。源码通过共享观测计数构建连接，阈值典型为 15。

Bundle Adjustment

联合调整位姿与地图点，使投影误差整体下降；惯性 BA 还把速度、bias、IMU 边加入图中。

Bias

IMU 测量偏置。源码分别维护 gyro bias 与 acc bias，并在预积分与优化中更新。

Atlas

多 Map 管理器。当前 Map 丢失时系统可以保存旧图并创建新图，LoopClosing 后续有机会合并。

RECENTLY_LOST

Tracking 不是从 OK 直接永远 LOST；短时失败进入中间状态，惯性已初始化时可用 IMU 预测暂时维持。

3. 常见失败：应该沿哪条源码路径排查？

单目初始化失败

  1. 先检查 mCurrentFrame.mvKeys.size() > 100。
  2. 检查 SearchForInitialization 是否得到 ≥100 matches。
  3. 检查 ReconstructWithTwoViews 是否成功、三角化点是否被大量剔除。
  4. 初始 GBA 后检查 medianDepth 与当前 KF TrackedMapPoints(1) >= 50，否则源码 ResetActiveMap。
Tracking.cc 初始化

IMU 初始化异常 / 被 reset

  1. InitializeIMU：Mono 至少 10 KFs、2 秒跨度。
  2. 检查优化后的 scale 是否 <0.1。
  3. LocalMapping 在早期还检查最近运动距离；mTinit<10s && dist<0.02m 时会标记 bad IMU。
  4. 时间戳跳变 >1s 在 inertial 模式会进入 reset/new map 路径。
InitializeIMU

运行中丢跟踪

  1. 确认初始 pose route：Reference KF / Motion Model / IMU Predict。
  2. TrackLocalMap 看局部地图搜索后 mnMatchesInliers。
  3. Mono+IMU：IMU 未初始化时 <50 失败；初始化后 <15 失败。
  4. 失败后看状态是 RECENTLY_LOST 还是 LOST；惯性初始化状态会影响是否 ResetActiveMap。
TrackLocalMap

BAD LOOP

  1. 先确认是否已通过 BoW + Sim3 + temporal coincidence。
  2. Inertial Map 最终还检查回环修正的旋转向量。
  3. roll/pitch 分量绝对值必须 <0.008，yaw <0.349，否则源码直接打印 BAD LOOP。
  4. 不要只调 BoW 阈值；错误可能来自地图/IMU 姿态不一致。
LoopClosing inertial gate

为什么不插关键帧？

  1. IMU 未初始化：Mono+IMU 首先看距上一 KF 是否 ≥0.25s。
  2. OnlyTracking 或 LocalMapping stop/requestStop 时会直接拒绝。
  3. 正常阶段看 c1a/c1b/c2、惯性时间条件 c3 (≥0.5s)、弱跟踪 c4。
  4. LocalMapping 忙时，Mono/IMU-Mono 不会像 stereo 那样在 queue<3 时强行接受。

5. 推荐的真实读码顺序

先从调用者开始：Examples → System → Tracking。
遇到视觉匹配：跳到 ORBextractor / ORBmatcher / Frame::ComputeBoW。
遇到地图对象：跳到 KeyFrame / MapPoint / Atlas。
遇到优化函数：先看调用处为什么调用，再进入 Optimizer 看顶点/边。
遇到失败：先按状态机和阈值排查，再去看数学。
